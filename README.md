# 做题系统

学生登录后按试卷做题，选择、判断、填空题自动判分，大题由老师判分；管理员管理学生账号、试卷和题目。

| 目录 | 内容 |
|---|---|
| `Hou` | 后端，Spring Boot 3.5 + MyBatis-Plus，接口说明见 [Hou/README.md](Hou/README.md) |
| `Qian` | 微信小程序，用微信开发者工具导入这个目录 |
| `Qian/web` | 网页版，打包进后端，启动后端后访问 `http://127.0.0.1:8080/` |

## 本地运行

1. 用 IDEA 打开 `Hou`，运行 `ExamApplication`（需要 JDK 17 或更高版本）。
2. 浏览器打开 `http://127.0.0.1:8080/`，或在微信开发者工具里导入 `Qian`。

本地默认使用 H2 数据库，数据在 `Hou/data`，不在仓库里。`application-dev.yml` 里的管理员密码只用于本地开发，正式部署请用 `mysql` 配置并通过环境变量设置密码。
